# 场景模板创建页视觉重设计划

## Context

当前模板创建的三个入口（对话、表单、示例提取）虽然已经改为两栏布局，但用户反馈：

1. 表单页底部的固定操作栏（红框处）会遮挡内容，视觉沉重。
2. 对话创建页的排版和传统聊天界面过于雷同，缺乏高级感。
3. 右侧实时预览卡片设计普通，像普通的配置面板，没有“作品/模板”应有的质感。

因此需要一次以“高级感、去模板化、沉浸式”为核心的视觉重设计，重点改造：

- 表单创建页：去掉固定底栏，将操作融入页面流。
- 对话创建页：从“左右两个白卡片”升级为“沉浸对话画布 + 侧边作品预览”。
- 实时预览卡片：升级为有质感的“模板成品卡片”。

## Recommended Approach

### 整体视觉方向

- **高级浅色基调**：大面积 `#f5f6f8` / `#fafafa` 背景，内容区用纯白 + 极淡投影，避免生硬的边框。
- **紫灰渐变强调**：沿用现有紫色主题，但改为更克制的渐变（`#7c3aed → #a78bfa`），用于头像、图标背景、主按钮、实时指示器。
- **非对称布局**：对话页 62% / 38%，表单页 58% / 42%，让主创作区更舒展，预览区像一本立起来的卡片。
- **去卡片化**：外层不再是一个大卡片包裹两栏，而是两栏直接在灰背景上形成“悬浮面板”。
- **玻璃/毛玻璃质感**：预览区和输入区使用轻微模糊与半透明，提升层次。

### 1. 表单创建页：去掉固定底栏

**当前问题**：`.wa-creator-form-bottom` 是 fixed 定位，始终压在最下方，用户滚动时感觉被挡住。

**新方案**：

- 移除 `position: fixed`，改为跟随内容流的底部操作区。
- 取消和生成按钮放在表单卡片右下角；左侧保留轻量提示文案。
- 将操作区做成表单卡片内部的最后一节，带顶部 1px 分隔线，不悬浮。
- 右侧实时预览卡片底部也放一条“生成提示词”的快捷入口，方便用户在不滚动左侧时直接操作。
- 滚动到底后，内容自然结束，没有遮挡。

### 2. 对话创建页：沉浸对话画布

**当前问题**：聊天和输入框被包在一个白卡片里，左右两栏都是矩形卡片，像配置后台。

**新方案**：

- 去掉外层 `.wa-creator-form-card` 包裹，让对话区直接坐落在灰背景上。
- 左侧对话区使用 62% 宽度，内部消息使用更宽松的排版：
  - AI 消息：左侧头像 + 圆角气泡，背景 `#ffffff`，细边框，头像使用紫灰渐变圆形。
  - 用户消息：右侧对齐，气泡背景使用紫色渐变文字 + 纯白背景边框，避免过于鲜艳的色块。
  - 消息间距加大到 20px，字体 14px/1.7，行高更舒展。
- 输入区做成“悬浮胶囊”：底部居中、带阴影、圆角 24px，看起来像浮在对话流之上，而不是贴底边框。
- 对话区右侧有一条 1px 的极淡竖线，自然分隔预览区。

### 3. 实时预览卡片：模板成品卡

**当前问题**：`.wa-creator-preview-card` 是带边框的矩形面板，字段用灰色小条堆叠，没有“成品”感。

**新方案**：

- 预览区使用 38% 宽度，sticky 定位。
- 卡片改为“纸张/成品卡”：
  - 白色背景，轻微圆角 16px，柔和多层阴影（`0 1px 2px rgba(0,0,0,0.02), 0 8px 24px rgba(0,0,0,0.06)`）。
  - 顶部是模板大图标 + 名称 + 角色/能力标签，图标背景使用紫灰渐变。
  - 中间用“字段清单”形式，每个字段左侧有一个小圆点状态（已收集/待收集），进度感强。
  - 底部放置主操作按钮（“进入确认页”/“生成提示词”），按钮使用紫色渐变 pill 形状。
- 增加“实时”状态：标题旁放一个呼吸灯绿点 + `Live` 字样。

### 4. 示例提取页

- 与表单页保持一致的视觉语言：左侧上传/示例输入面板，右侧识别结果预览卡。
- 去掉居中卡片包裹，改为两栏悬浮面板。

## Files to Modify

- `src/views/WorkAssistant.js`
  - `renderCreatorFormView()`：重构 HTML，去掉固定底栏，将操作区移入表单卡片内部和右侧预览卡底部。
  - `renderCreatorChatView()`：去掉外层卡片，改用新布局结构。
  - `renderConversationMessages()` / `renderConversationPreview()`：调整 DOM 类名和结构以适配新样式。
  - `renderCreatorExtractView()`：同步调整为新布局结构。
- `src/style.css`
  - 重定义 `.wa-creator-form-new`、`.wa-creator-form-layout`、`.wa-creator-form-card`。
  - 新增/重定义 `.wa-creator-chat-layout`、`.wa-creator-chat-main`、`.wa-creator-chat-side`、`.wa-conversation-messages`、`.wa-message-*`、`.wa-conversation-input-area`。
  - 重定义 `.wa-creator-preview-card` 及其子元素为“成品卡”风格。
  - 删除/覆盖 `.wa-creator-form-bottom` 的 fixed 定位样式。

## Verification

- 启动 `npm run dev`。
- 分别进入“对话创建”“表单创建”“从示例提取”三个 Tab，检查：
  - 无固定底栏遮挡内容，滚动到底自然结束。
  - 对话页视觉不再像传统聊天后台，输入区为悬浮胶囊，消息排版舒展。
  - 右侧预览卡片像“模板成品卡”，有 Live 指示和字段收集进度。
  - 三页在 1440px 和 1024px 下均无错位。
- 运行 `python verify-creator-review.py`，确保创建流程（表单/对话/提取）仍能通过。
