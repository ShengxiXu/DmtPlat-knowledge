# 新建知识库功能重构计划

## 需求分析
用户反馈当前新建知识库功能交互不够人性化，体验不好。需要重构：
- 简化创建流程
- 优化页面布局
- 提升交互体验

## 当前问题分析
1. **流程繁琐**：3步流程，用户需要多次点击
2. **选择分离**：创建方式和类型分开选择，不够直观
3. **反馈不足**：选择后缺乏即时反馈
4. **配置复杂**：专项配置表单信息量大，容易让人望而却步

## 改进方案

### 1. 简化流程（2步完成）
- **第一步**：选择知识库类型和模板（合并）
- **第二步**：基本信息和配置确认

### 2. 优化布局
- 卡片式选择，类型和模板整合展示
- 右侧实时预览面板
- 配置项折叠展示

### 3. 增强交互
- 即时状态反馈
- 平滑过渡动画
- 清晰的操作引导

### 4. 视觉优化
- 现代简洁的UI设计
- 合理的信息层级
- 响应式布局

## 文件清单
| 文件 | 修改内容 |

## 步骤
1. 重构 CreateKBModal，实现2步流程
2. 简化模板选择器，与类型选择整合
3. 优化配置表单，支持折叠展开
4. 更新样式文件
5. 测试验证

## 风险评估
- 中风险：涉及多处文件修改
- 需要注意：保持与现有代码的兼容性
