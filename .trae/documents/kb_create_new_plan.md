# 新建知识库页面实现计划

## 需求分析
实现整合模板与多数据源的新建知识库功能：
1. 支持空白知识库和模板创建两种方式
2. 支持在一个知识库中添加多个数据源（文档、网页、数据库、问答）
3. 数据源可配置、可删除
4. 模板可预设数据源配置

## 文件清单
| 文件 | 修改内容 |
|------|----------|
| src/components/CreateKBModal.js | 重构模态框组件，实现新流程 |
| src/components/DataSourceForm.js | 新增数据源配置表单组件 |
| src/data/templates.js | 更新模板数据结构 |
| src/style.css | 添加新样式 |

## 实现步骤
1. 更新模板数据结构，支持预设数据源
2. 创建数据源配置表单组件
3. 重构 CreateKBModal，实现完整流程
4. 添加样式
5. 测试验证
