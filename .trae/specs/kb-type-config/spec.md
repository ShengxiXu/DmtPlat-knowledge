# 知识库类型配置与模板创建 - 产品需求文档

## Overview
- **Summary**: 重新设计知识库创建流程，为4种知识库类型（文档、网页、数据库、问答）提供差异化配置项，并添加类似飞书知识库的模板创建功能。
- **Purpose**: 解决当前所有知识库类型配置项相同的问题，让不同类型的知识库有针对性的配置选项；同时提供模板创建功能，简化知识库创建流程。
- **Target Users**: 知识库管理员、普通用户

## Goals
- 为4种知识库类型设计差异化的配置项
- 添加知识库模板创建功能
- 提供直观的创建流程引导

## Non-Goals (Out of Scope)
- 不涉及知识库内容编辑功能
- 不涉及权限管理的详细配置
- 不涉及数据导入/导出功能

## Background & Context
当前系统支持4种知识库类型：文档、网页、数据库、问答，但创建时配置项完全相同，无法体现不同类型的特性。参考飞书知识库的模板化创建方式，需要提供更专业的创建体验。

## Functional Requirements
- **FR-1**: 文档类型知识库配置 - 支持文档上传、格式设置、索引配置
- **FR-2**: 网页类型知识库配置 - 支持URL采集、爬取规则、更新频率设置
- **FR-3**: 数据库类型知识库配置 - 支持数据库连接、表选择、字段映射
- **FR-4**: 问答类型知识库配置 - 支持问答对导入、训练配置、评分规则
- **FR-5**: 模板创建功能 - 提供预设模板，一键创建知识库

## Non-Functional Requirements
- **NFR-1**: 创建表单响应时间 < 500ms
- **NFR-2**: 支持深色/浅色主题适配
- **NFR-3**: 表单验证实时反馈

## Constraints
- **Technical**: 当前使用原生JS + Vite构建，无前端框架
- **Business**: 保持与现有UI风格一致

## Assumptions
- 用户熟悉基本的知识库概念
- 用户了解不同类型知识库的用途

## Acceptance Criteria

### AC-1: 文档知识库配置
- **Given**: 用户选择创建"文档"类型知识库
- **When**: 进入配置页面
- **Then**: 显示文档相关配置项（文件格式、索引策略、分块大小）
- **Verification**: `human-judgment`

### AC-2: 网页知识库配置
- **Given**: 用户选择创建"网页"类型知识库
- **When**: 进入配置页面
- **Then**: 显示网页相关配置项（URL列表、爬取深度、更新周期）
- **Verification**: `human-judgment`

### AC-3: 数据库知识库配置
- **Given**: 用户选择创建"数据库"类型知识库
- **When**: 进入配置页面
- **Then**: 显示数据库相关配置项（连接信息、表选择、字段映射）
- **Verification**: `human-judgment`

### AC-4: 问答知识库配置
- **Given**: 用户选择创建"问答"类型知识库
- **When**: 进入配置页面
- **Then**: 显示问答相关配置项（问答对导入、训练参数、评分规则）
- **Verification**: `human-judgment`

### AC-5: 模板创建功能
- **Given**: 用户进入知识库创建页面
- **When**: 选择"按模板创建"
- **Then**: 显示模板列表，选择后自动填充配置
- **Verification**: `human-judgment`

## 知识库类型配置设计

### 1. 文档知识库 (Document KB)

**适用场景**: 企业文档管理、产品手册、技术文档、培训资料等

**核心配置项**:

| 配置分组 | 配置项 | 类型 | 说明 | 默认值 | 必填 |
|----------|--------|------|------|--------|------|
| 文件管理 | 支持格式 | 多选 | PDF, Word(docx), Markdown(md), TXT, Excel(xlsx) | PDF, Word, Markdown | 是 |
| 文件管理 | 最大文件大小 | 选择 | 10MB / 50MB / 100MB / 500MB | 50MB | 是 |
| 文件管理 | 是否允许上传 | 开关 | 启用/禁用文件上传功能 | 启用 | 是 |
| 内容处理 | 分块策略 | 单选 | 按段落 / 按字符数 / 智能分块(语义感知) | 智能分块 | 是 |
| 内容处理 | 分块大小范围 | 输入框 | 最小-最大字符数 | 300-1000 | 是 |
| 内容处理 | 是否提取图片 | 开关 | 从文档中提取图片内容 | 开启 | 否 |
| 内容处理 | OCR识别 | 开关 | 对图片内容进行文字识别 | 开启 | 否 |
| 索引配置 | 索引优先级 | 单选 | 高 / 中 / 低 | 中 | 是 |
| 索引配置 | 是否创建摘要 | 开关 | 自动生成文档摘要 | 开启 | 否 |
| 索引配置 | 摘要长度 | 输入框 | 摘要字符数限制 | 200 | 否 |

**配置流程图**:
```
选择文档类型 → 设置支持格式 → 配置分块策略 → 设置索引优先级 → 完成
```

### 2. 网页知识库 (Web KB)

**适用场景**: 网站内容采集、竞品分析、行业资讯聚合、新闻监控等

**核心配置项**:

| 配置分组 | 配置项 | 类型 | 说明 | 默认值 | 必填 |
|----------|--------|------|------|--------|------|
| 爬取配置 | 起始URL | 多行输入 | 爬取的起始地址，支持多个URL | - | 是 |
| 爬取配置 | 爬取深度 | 输入框 | 最大爬取层级(1-10) | 3 | 是 |
| 爬取配置 | 最大页面数 | 输入框 | 最大爬取页面数量 | 100 | 是 |
| 爬取配置 | 爬取间隔 | 输入框 | 请求间隔(毫秒)，防止被封禁 | 1000 | 是 |
| 域名控制 | 域名限制 | 开关 | 只爬取相同域名下的页面 | 开启 | 是 |
| 域名控制 | 允许的域名 | 多行输入 | 白名单域名列表 | - | 否 |
| 域名控制 | 排除路径 | 多行输入 | 排除的URL模式（支持正则） | - | 否 |
| 内容提取 | 提取规则 | 选择 | 智能提取 / CSS选择器 / XPath | 智能提取 | 是 |
| 内容提取 | 自定义选择器 | 输入框 | CSS选择器或XPath表达式 | - | 否 |
| 内容提取 | 是否提取链接 | 开关 | 自动提取页面中的链接 | 开启 | 否 |
| 更新策略 | 更新周期 | 单选 | 每天 / 每周 / 每月 / 手动 | 每周 | 是 |
| 更新策略 | 更新时间 | 输入框 | 定时更新的具体时间 | 02:00 | 否 |
| 更新策略 | 更新模式 | 单选 | 全量更新 / 增量更新 | 增量更新 | 是 |

**配置流程图**:
```
输入起始URL → 配置爬取深度和数量 → 设置域名规则 → 配置内容提取 → 设置更新策略 → 完成
```

**适用场景**: 业务数据查询、报表分析、数据中台、企业级数据检索等

| 连接配置 | 主机地址 | 输入框 | 数据库服务器地址 | - | 是 |
| 连接配置 | 端口 | 输入框 | 数据库端口 | MySQL:3306, PG:5432 | 是 |
| 连接配置 | 数据库名 | 输入框 | 目标数据库名称 | - | 是 |
| 连接配置 | 用户名 | 输入框 | 数据库登录用户名 | - | 是 |
| 连接配置 | 密码 | 密码框 | 数据库登录密码 | - | 是 |
| 连接配置 | 连接测试 | 按钮 | 测试数据库连接是否成功 | - | - |
| 数据配置 | 表选择 | 多选 | 选择要同步的数据表 | - | 是 |
| 数据配置 | 字段映射 | 表格 | 选择需要索引的字段及字段类型 | - | 是 |
| 数据配置 | 主键字段 | 选择 | 用于增量更新的唯一标识字段 | - | 是 |
| 数据配置 | 内容字段 | 多选 | 作为主要检索内容的字段 | - | 是 |
| 同步策略 | 更新策略 | 单选 | 全量同步 / 增量同步 | 增量同步 | 是 |
| 同步策略 | 同步频率 | 单选 | 实时 / 每小时 / 每天 / 每周 | 每天 | 是 |
| 同步策略 | 同步时间 | 输入框 | 定时同步的具体时间 | 03:00 | 否 |
| 同步策略 | 增量字段 | 选择 | 用于判断增量的时间戳字段 | - | 否 |

**配置流程图**:
```
选择数据库类型 → 输入连接信息 → 测试连接 → 选择数据表 → 配置字段映射 → 设置同步策略 → 完成
```

### 4. 问答知识库 (QA KB)

**适用场景**: 智能客服、FAQ问答、知识库问答机器人、内部知识问答等

**核心配置项**:

| 配置分组 | 配置项 | 类型 | 说明 | 默认值 | 必填 |
|----------|--------|------|------|--------|------|
| 数据导入 | 问答对导入 | 文件上传 | 支持CSV/JSON格式，包含question和answer字段 | - | 否 |
| 数据导入 | 导入模式 | 单选 | 覆盖导入 / 追加导入 | 追加导入 | 否 |
| 训练配置 | 训练轮数 | 输入框 | AI模型训练次数(1-20) | 5 | 是 |
| 训练配置 | 学习率 | 滑块 | 模型学习率(0.001-0.1) | 0.01 | 是 |
| 训练配置 | 批次大小 | 输入框 | 每批训练数据量 | 32 | 是 |
| 匹配配置 | 相似度阈值 | 滑块 | 匹配相似度门槛(0-1) | 0.75 | 是 |
| 匹配配置 | 最大返回数 | 输入框 | 单次返回的答案数量(1-10) | 3 | 是 |
| 匹配配置 | 评分规则 | 选择 | 准确率优先 / 相关性优先 / 混合排序 | 混合排序 | 是 |
| 对话配置 | 启用意图识别 | 开关 | 识别用户问题意图并分类 | 开启 | 否 |
| 对话配置 | 启用多轮对话 | 开关 | 支持上下文理解的多轮对话 | 开启 | 否 |
| 对话配置 | 上下文窗口 | 输入框 | 保留的历史对话轮数 | 5 | 否 |
| 对话配置 | 实体识别 | 开关 | 识别问题中的实体信息 | 开启 | 否 |
| 增强配置 | 反问澄清 | 开关 | 当问题不明确时自动反问 | 开启 | 否 |
| 增强配置 | 答案置信度 | 开关 | 显示答案的置信度分数 | 开启 | 否 |
| 增强配置 | 拒绝回答 | 开关 | 对低置信度问题拒绝回答 | 开启 | 否 |

**配置流程图**:
```
导入问答对(可选) → 配置训练参数 → 设置匹配规则 → 配置对话特性 → 开启增强功能 → 完成
```

## UI设计要点

### 类型选择界面
- 卡片式布局展示4种类型
- 每个卡片显示：类型图标、名称、描述、适用场景标签
- 选中状态：边框高亮 + 背景色变化
- 悬停效果：阴影加深

### 配置表单
- 分步表单设计（步骤指示器）
- 第一步：选择创建方式 + 知识库类型
- 第二步：基本信息（名称、描述、可见性）
- 第三步：专项配置（根据类型动态切换）
- 实时验证提示（红色错误/绿色成功）

### 模板选择界面
- 左侧分类树 + 右侧模板列表
- 顶部搜索框（支持按名称、标签搜索）
- 模板卡片：图标、名称、描述、标签
- 预览弹窗：配置摘要、推荐文档、适用场景

### 响应式设计
- 桌面端：完整的左右布局
- 平板端：分类树折叠为下拉选择
- 移动端：分步展示，模态框全屏显示

### 交互细节
- 步骤切换动画（淡入淡出 + 滑动）
- 表单验证实时反馈
- 数据库连接测试按钮
- 模板搜索实时过滤
- 配置项依赖关系联动（如选择数据库类型后端口自动填充）
